# Thrive Africa Cybersecurity Internship

## Overview

This repository documents my practical work and technical deliverables completed during my **Cybersecurity Internship with Thrive Africa**.

The internship provides hands-on experience in cybersecurity, including reconnaissance, network enumeration, vulnerability assessment, risk analysis, threat modeling, and security mitigation.

This repository will be continuously updated as I progress through the internship.

---

## Objectives

The main objectives of this internship are to:

* Apply cybersecurity concepts in practical laboratory environments.
* Perform reconnaissance and network enumeration.
* Identify exposed services and potential vulnerabilities.
* Conduct vulnerability assessments using industry-standard tools.
* Analyze and prioritize cybersecurity risks.
* Develop appropriate mitigation and remediation strategies.
* Strengthen practical skills in cybersecurity assessment and defensive security.
* Document technical findings in a clear and professional manner.

---

## Weekly Activities

### Week 01 — Threat Modeling

**Focus:** Understanding an organization's assets, infrastructure, attack surface, and potential threats.

Activities included:

* Defining the organization's environment and critical functions.
* Identifying and classifying critical assets.
* Creating an asset inventory.
* Designing a high-level network architecture.
* Identifying potential entry points and attack surfaces.
* Developing a threat model using structured threat-analysis concepts.

**Key Deliverables:**

* Company Overview
* Asset Inventory
* Network Diagram
* Threat Model

---

### Week 02 — Reconnaissance & Network Enumeration

**Focus:** Identifying hosts, ports, services, and technologies within a controlled laboratory environment.

Activities included:

* Host discovery.
* Network reconnaissance.
* Port scanning.
* Service and version enumeration.
* Identification of exposed services.
* Initial analysis of potentially vulnerable services.

**Tools Used:**

* Nmap
* Netdiscover
* WHOIS
* DNS reconnaissance tools

---

### Week 03 — Vulnerability Assessment

**Focus:** Identifying and evaluating vulnerabilities discovered within the laboratory environment.

Activities included:

* Vulnerability scanning.
* Web security assessment.
* Service vulnerability identification.
* CVE research.
* Vulnerability severity and impact analysis.
* Comparison of findings from different security assessment tools.

**Tools Used:**

* Nessus
* Nikto
* OWASP ZAP
* Nmap

---

### Week 04 — Risk Analysis & Prioritization

**Focus:** Analyzing identified vulnerabilities and determining their associated cybersecurity risks.

Activities included:

* Reviewing vulnerabilities identified during previous assessments.
* Evaluating likelihood and potential impact.
* Assigning risk levels.
* Prioritizing security risks.
* Developing mitigation and remediation recommendations.
* Creating a risk register.
